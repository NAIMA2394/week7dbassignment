📊 Data Analysis and Visualization Assignment
🎯 Objective
This project demonstrates how to:

Load and explore a dataset using Pandas.

Perform basic data analysis such as summarizing statistics and grouping data.

Visualize data using Matplotlib and Seaborn.

Gain insights through structured exploration and visualization.

📁 Dataset Used
Iris Dataset
The Iris dataset contains 150 records of iris flowers with the following columns:

sepal_length

sepal_width

petal_length

petal_width

species

🛠️ Tools & Libraries
Python

Pandas

Matplotlib

Seaborn

✅ Tasks Completed
Task 1: Load and Explore the Dataset
Loaded the dataset using Pandas.

Displayed the first few rows with .head().

Checked for missing values and data types.

Cleaned the dataset (none needed for Iris).

Task 2: Basic Data Analysis
Used .describe() to get mean, median, and standard deviation.

Grouped data by species to find average measurements.

Identified patterns in flower types and measurements.

Task 3: Data Visualization
Created the following plots:

Line chart for petal length by index.

Bar chart comparing average petal length per species.

Histogram of sepal width.

Scatter plot of sepal length vs petal length.

Customized plots with labels, titles, and legends.
